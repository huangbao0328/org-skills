# 可贴课本课表

把学校官方课表做成可打印、可贴进课本封面内侧的紧凑课表（默认 A6 横版卡片 + A4 裁切打印版）。

## 硬规则（易错，必守）

1. **课名字符级对齐学校原表**：科目名、后面的数字后缀（如「音乐1」「美术2」「综合课1」「体育健康1」）、斜杠写法（如「阅读/书法」）、括号说明（如「班队」）一律照抄。**禁止**为紧凑、美观或「孩子好认」擅自删改、合并或简化课名。
2. **交付前对照原图/原文逐格核对**：周一至周五 × 各节次，逐格 diff；漏数字、漏「健康」、漏单双周标注都算未完成。
3. **权威源是用户给的课表**（照片或文字），不是记忆里的科目清单，也不是你觉得更合理的课表。
4. 早读老师名、单双周（单/双）若原表有，须保留；用户明确要求去掉时再去。

## 步骤

1. 若手头没有课表内容：请用户发照片或周一到周五各节文字；收到后再做，不猜。
2. 从照片/文字抽出完整网格：节次、时间、周一至周五科目（含上述后缀与标注）。
3. 做 HTML 卡片：约 A6 横版（≈148×105 mm）、科目分色、班级/学期写在页眉；同时包一层 A4 裁切页（虚线框 +「实际大小 100%」打印说明），方便家用打印机。
4. 用本机 Chrome headless 打成 PDF，并出 PNG 预览给用户看一眼。
5. 用户确认后再视为完成；若指出漏项，改 HTML → 重出 PDF/预览，不要只口头说改了。

## 产出

- `kebiao-a4-print.pdf`：推荐打印
- `kebiao-a6.pdf`：纯卡片尺寸
- `preview-*.png`：聊天预览

默认目录：`/workspace/<孩子名或任务>-timetable/`。

## 已知失败案例（2026-10-17）

- **错**：为贴课本排版，把「音乐1 / 美术1 / 美术2 / 综合课1 / 体育健康1」收成「音乐 / 美术 / 综合课 / 体育」。
- **果**：用户一眼看出与学校课表不符，要求补回。
- **改**：字符级对齐 + 交付前逐格核对；本 Skill 将此条列为硬规则。
