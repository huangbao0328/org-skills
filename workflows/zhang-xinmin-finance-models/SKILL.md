# 张新民财报决策思维模型

信源：《财报掘金》《张新民教你读财报》《火眼金睛读财报》。工作页可回访：[张新民财报三书｜决策思维模型](https://cursor.com/canvas/store-dd39dfe7-f4f1-46c0-a4a9-5ed637fc17bf/b874eae9-a296-4836-b2a5-25400b325b89)。材料目录 `/workspace/zhang-xinmin-finance/`（热门划线/目录，非全书正文）。

## 怎么用

1. 先跑**统一流水线**扫三表。
2. 再点选相关**模型**，用 A/B/C/D 门槛写判断（不编造；缺数标 D）。
3. 用文末**决策检查清单**收口，输出可执行洞察（该不该投/加码/排雷/再要什么数据）。

门槛四态：**A 符合 / B 不符 / C 排除 / D 数据不足**。

## 统一分析流水线

顺序：利润表（面子）→ 现金流量表（日子）→ 资产负债表（底子）→ 三表勾稽与母子公司 → 战略与前景。

1. **利润表**：收入增速 → 毛利/毛利率 → 还原核心利润 → 三支柱 → 两搅局（信用/资产减值）→ 净利润含金量
2. **现金流**：经营现金流对核心利润充分性 → 投资是否匹配战略 → 筹资谁在输血、用去何处 → 自由现金流粗算
3. **资产负债表**：资产规模动因 → 流动结构 → 负债经营性 vs 金融性 → 增长动力（利润/经营负债/贷款）
4. **收口**：资产-收入-核心利润-经营现金流是否协同；母公司 vs 合并；八看；爆雷科目清单

隐喻：资产负债表是底子，利润表是面子，现金流量表是日子。

## 十模型（关键问题 + 门槛要点）

### 1. 核心利润
- 问：主业经营活动是否真正赚钱？
- A：核心利润为正且可持续；与毛利率方向一致
- B/C：营业利润好看但核心利润弱；靠补贴/投资/处置粉饰
- 反模式：把营业利润或净利润当主业利润

### 2. 三支柱 · 两搅局
- 问：营业利润靠什么凑？谁在搅局？
- A：支柱一（核心利润）占主导；补贴/杂项可解释；减值匹配现实
- 反模式：只看净利润增速；把补贴当核心竞争力

### 3. 核心利润获现率
- 问：利润有没有变成真金白银？
- A：经营现金流净额 /（核心利润+其他收益）约在 1.2～1.5（经验区间，行业待标定）
- B/C：长期偏低；有利润没现金；靠输血续命
- 反模式：只看净利润；把筹资流入当赚钱能力

### 4. 两头吃
- 问：对上下游资金占用能力强不强？
- A：应付相对存货偏大；预收/合同负债强于应收
- 反模式：把低流动比率一律当风险（强势企业可长期偏低）

### 5. 资产质量
- 问：资产是实力还是爆雷底盘？
- A：经营资产与收入同向；周转改善；不良可控
- 反模式：资产越大越强；用净值算周转掩盖闲置

### 6. 造血 vs 输血
- 问：靠自我造血还是外部输血？
- A：经营性负债+利润积累是主动力；金融负债维持必要最低
- 反模式：资产负债率一刀切；忽视经营性负债可以是竞争力

### 7. 张氏八看
- 看战略 / 资产管理与竞争力 / 效益与质量 / 成本决定机制 / 项目质量 / 风险 / 价值 / 前景
- 反模式：把杜邦当终点；只追 ROE

### 8. 轻重资产
- 问：重资产能否撑住收入与利润？轻资产是否真能推动收入？
- 反模式：以为轻就一定好；推不动收入的轻也是重

### 9. 爆雷地图
- 巡检：货币资金、应收、存货、固定资产、无形资产、长期股权投资、商誉、在建工程
- 联动审计意见与关键审计事项
- 反模式：只盯利润表

### 10. 合并 vs 母公司
- 问：集团是自己干，还是投资管控「飞」起来？
- 反模式：只看合并报表

## 质量三件套

- **资产质量**：规模≠实力；经营资产须推动收入；决策错配难事后补救
- **利润质量**：核心利润主导；扩张期可看毛利额；公允价值变动常无对应可支配资产
- **现金流质量**：盈利≠赚钱；获现率；输血纪律

## 决策检查清单（评估公司 / 一笔投入）

1. 还原核心利润与三支柱
2. 算核心利润获现率并解释偏离
3. 检查两头吃（应收 vs 预收；存货 vs 应付）
4. 资产是否推动收入（固资/无形/商誉）
5. 增长动力：利润 / 经营性负债 / 贷款 谁为主
6. 爆雷地图巡检
7. 母公司 vs 合并看战略
8. 审计意见与关键审计事项
9. 该笔投入是强化核心利润与获现，还是堆低效资产
10. 材料不足一律标 D

## 输出格式（给决策者）

- 一句话结论（投/不投/观望/先要数）
- 流水线发现（3～5 条）
- 模型门槛表（用到的模型：A/B/C/D + 一句证据）
- 否决项与待补数据
- 可选下一步（再看哪张表 / 要哪家案例对标）
