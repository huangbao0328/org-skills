## 步骤

1. **先打开 Page**，按「部门 / 评级 / 分区」筛选，不要凭记忆复述 star 数。
2. **按部门默认入口**：
   - 大内：`awesome-opus5-5-videos`、`mg-styles-15`、`opus-video-prompts`
   - 大全：`lemo-opuscar`、`pdoom-video`、`ClaudeAnimationBase`（对照可看 `PDoomVideo`）
   - 小信 / 通用：`awesome-opus5-5-videos`、`awesome-claude-5-5-videos`、`opus-video-prompts`
3. **交给对方时只给**：仓库 URL + Page 里该条的用途/上手/风险；不附原作者微信群、答疑群、付费课。
4. **需要更新工具箱时**（新仓、star 大变、仓 archived）：
   - 用 GitHub API / `gh api repos/{owner}/{repo}` 核验存在性、star、updated、README、license、是否 archived
   - 更新核验笔记，再 EditCanvas / WriteCanvas 同一 Page（同一主题不新建第二页）
   - 重大变更同步飞书「内部应用与Skill清单」对应行备注
5. **本 Skill 不做**：安装依赖、跑渲染、生成成片、替用户付费下素材。
