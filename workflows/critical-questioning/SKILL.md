# 批判性提问（critical-questioning）

**文档定位**：工程约定。接收论断/数据/方案、以及自身产出结论之前，按本 Skill 完成批判性提问。  
**与手册分工**：手册规则 **24.4** 只留触发、红线、信号跳步钩子；**本 Skill 留 10 步全表**。  
**与其他文档**：认知锚点 / 规则 24.1–24.3 管「想得对不对」；品味 `taste-output` 管「像不像我」；本 Skill 管「信不信」。  
**框架来源**：《学会提问》10 步顺序转写；删冗长原文摘录与书摘，只留触发+问法+一句要点。  
**优先级**：红线 > 启动判断 > 信号跳步/10 步 > 提问策略。  

---

## 0. 红线（4 条）

触发即 **停** → **报**命中第几条 → **问**（给选项，不问开放题）：

1. **未问先评**：未走提问流程就对论断/方案给出接受或拒绝的评价。
2. **二分式结论**：重大问题给出简单「是/不是」式结论。
3. **数据不问来源**：引用统计数字、比例、估计值之前不问「这些数据是怎么得来的」。
4. **同类偏移不升级**：同一根因「未问先评」累计 ≥ 3 次且未升级为正式锚点。

## 1. 启动判断

**必走**（三类）：

- 用户给出需求、论断、方案、数据，要求评价、采纳或基于此产出；
- AI 即将给出带结论性质的产出（决策建议、选型、评审意见）；
- 外部资料（搜索结果、文档、报告）中的观点将作为产出依据。

**跳过**：纯执行任务（按明确指令改代码、格式化、搬运内容）。

## 2. 提问流程（10 步全表）

顺序即书上章节序，勿乱：①–④ 先弄清对方在说什么 → ⑤–⑥ 查推理与证据 → ⑦–⑧ 质疑因果与数据 → ⑨ 找省略 → ⑩ 才下结论。命中信号表可跳步。

### ① 论题和结论是什么

- **触发**：接触任何一段话之后。
- **问法**：论题是什么？结论是什么？描述性（是不是/是什么）还是规定性（该不该/对不对）？
- **要点**：找准论题和结论是后续所有讨论的原动力。

### ② 理由是什么

- **触发**：找到结论之后。
- **问法**：支撑结论的理由是什么？每条有没有证据？没找到理由和证据前，不评价结论价值。
- **要点**：评价之前要先等一等。

### ③ 哪些词语意思不明确

- **触发**：认同结论之前。
- **问法**：理由和结论里关键词（如「合规」「高效」）的确切含义？有歧义先澄清再评价。
- **要点**：想说服你的人有责任澄清歧义；词越抽象越易多重解读。

### ④ 价值观假设和描述性假设是什么

- **触发**：推敲理由与结论的衔接时。
- **问法**：从理由到结论有哪些没说出口但必不可少的连接假设？理由本身又依赖哪些未明说信念？
- **要点**：只有认同未明说信念，论证才对你成立。

### ⑤ 论证中有没有谬误

- **触发**：检查推理过程时。
- **问法**：有没有人身攻击等欺骗手段——打人而不反驳理由？叫不出谬误名没关系，问对问题就能找到。
- **要点**：品格/外表通常与论证质量无关；勿被干扰项带跑。

### ⑥ 证据的效力如何

- **触发**：对方抛出证据时。
- **问法**：证据属哪类——个人经历、典型案例、当事人证言、专家陈述、个人观察、调查研究？个人观察与证言效力低；调查研究看样本与提问方式。见解不是证据。
- **要点**：证据接近事实、远离纯见解时才有说服力。

### ⑦ 有没有替代原因

- **触发**：听到「因为 A 所以 B」式因果断言时。
- **问法**：这个结果还能有什么别的言之成理的解释？专家通常不主动透露，得自己找。
- **要点**：警惕确认偏误、相关≠因果、「在此之后」≠「因此」。

### ⑧ 数据有没有欺骗性

- **触发**：看到统计数字时。
- **问法**：这些数据是怎么得来的？细节越多越好。换呈现方式会不会骗人？
- **要点**：统计数据可能且经常撒谎；估计有用也可能有欺骗性。

### ⑨ 有什么重要信息被省略了

- **触发**：快被说服、准备下结论前。
- **问法**：呈现信息的人有什么目的？哪些不利信息被省略？谁分享这数据，就是要达谁的目的。
- **要点**：相信有力理由时更应犹豫片刻，想想对方可能没告诉你的。

### ⑩ 能得出哪些合理的结论

- **触发**：收尾做判断时。
- **问法**：这组理由只能导出这一个结论吗？还有哪些合理结论？避免二分式，培养灰度思维。
- **要点**：重大问题很少能用简单「是」或绝对「不是」回答；可用限定条件与具体语境避免二分。（与手册规则 21 决策三问并列。）

## 3. 信号跳步表

不必每次从①走到⑩。命中场景直接跳：

| 场景 | 跳到 |
| --- | --- |
| 「因为 A 所以 B」式因果断言 | ⑦ 替代原因 |
| 统计数字、百分比、估计值 | ⑧ 数据欺骗性 |
| 亲身经历、个案、当事人证言、专家说 | ⑥ 证据效力 |
| 关键词有歧义（如「合规」「高性能」） | ③ 词义澄清 |
| 被要求「你觉得这个方案行不行」 | 从①顺序走完 |
| 快被说服、准备接受 | ⑨ 省略信息 |
| AI 自己要产出结论 | ⑩ + 红线 2 自查 |

## 4. 提问策略

- **单条最多 1 个澄清问**（与手册规则 24.6 / 沟通纪律一致）；不连环发问。
- **能自查先自查**：自己检索或验证能答的（数据怎么得来、有无替代原因），先自查；查不到再问用户。
- 提问目的是评估论证并落到更有价值的结论或行动，不是显示聪明。
- 了解谈话对象；正确提问可能带来不适，注重策略。
